# Проект Асинхронная сетевая обработка команд (Async Network Bulk Processor)

## Описание проекта

Данный проект реализует асинхронный TCP-сервер для обработки пакетных команд, поступающих по сети от множества клиентов. Он декомпозирован на три основные компонента:

1.  **Библиотека `libasync.so`**: ядро обработки команд, реализованное с использованием многопоточности (паттерн "Наблюдатель" и "Диспетчер задач").
2.  **Клиентское приложение `bulk`**: консольная утилита, которая использует библиотеку для чтения команд из стандартного ввода (`stdin`) и асинхронного логирования в консоль и файлы.
3. **Сетевой сервер `bulk_server`**: асинхронный TCP-сервер, принимающий команды от сетевых клиентов и распределяющий их обработку.

Проект поддерживает параллельную обработку нескольких независимых контекстов команд через C-интерфейс библиотеки (`connect`/`receive`/`disconnect`).

## Структура проекта

Проект организован в соответствии со стандартными практиками C++/CMake. Исходный код разделен на базовую (однопоточную) версию и многопоточные расширения:  
```
.
├── include/               # Заголовочные файлы
│   ├── async/            # Публичный API библиотеки (async.h)
│   ├── base/             # Базовые компоненты (однопоточные)
│   │   ├── BulkProcessor.h    # Обработчик пакетных команд
│   │   ├── Command.h          # Представление команды
│   │   ├── ConsoleLogger.h    # Вывод в консоль
│   │   ├── FileLogger.h       # Вывод в файл
│   │   ├── Observer.h         # Интерфейс Наблюдателя
│   │   └── Subject.h          # Интерфейс Издателя
│   └── mt/               # Многопоточные компоненты
│       ├── AsyncLoggerAdaptor.h    # Адаптер для асинхронного логирования
│       ├── Dispatcher.h            # Диспетчер потоков
│       ├── ThreadSafeQueue.h       # Потокобезопасная очередь
│       └── ThreadsafeFileLogger.h  # Потокобезопасный файловый логгер
├── src/                  # Файлы реализации
│   ├── async/            # Реализация публичного API (async.cpp)
│   ├── bulk_server/      # Сетевой сервер
│   │   └── main.cpp      # Основной файл сервера
│   ├── mt/               # Многопоточные реализации
│   │   └── Dispatcher.cpp # Реализация диспетчера
│   └── main.cpp          # Клиентское приложение
├── unit_tests/           # Юнит-тесты
│   ├── boost/            # Тесты с использованием Boost.Test
│   └── gtest/            # Тесты с использованием Google Test
└── scripts/              # Вспомогательные скрипты
    └── check_bulk_server.sh  # Скрипт тестирования сервера
```

## Сборка проекта с использованием CMake

Для сборки проекта вам понадобится компилятор C++17 (например, GCC 9+ или Clang 9+), CMake версии 3.12 или выше и библиотеки Boost (требуется для сетевого сервера). 

### 1. Клонирование репозитория (включая субмодули)

`git clone https://github.com/r0973/otus-cpp.git`  
`cd otus-cpp`  
`git checkout feature/asyn_network_bulk_parser`

### 2. Создание каталога сборки

`mkdir build`  
`cd build`  

### 3. Конфигурация проекта

`cmake ..`  

#### Опционально: Вы можете отключить сборку тестов Google Test или Boost, добавив параметры при конфигурации:

`cmake .. -DWITH_GOOGLE_TEST=OFF -DWITH_BOOST_TEST=OFF`  

### 4. Сборка проекта
`cmake --build .`  

### 5. Установка проекта (Копирование артефактов в build/install/)
Этот шаг копирует скомпилированные файлы (`bulk`, `libasync.so`, `run_test.sh`, `check_bulk_server.sh`) в целевой каталог `build/install/bin` и `build/install/lib`.

`cmake --install .`  

### 6. Запуск и тестирование
После установки все необходимые файлы находятся в каталоге `build/install/`.

#### 6.1. Запуск сетевого сервера  
```bash
cd build/install/bin/
./bulk_server <port> <bulk_size>
```
Пример:  
```bash
./bulk_server 9000 3
```

#### 6.2. Подключение клиентов
Клиенты могут подключаться с помощью любых TCP-клиентов. Пример с netcat:
```bash
# Клиент 1
seq 0 9 | nc localhost 9000

# Клиент 2 (параллельно)
seq 10 19 | nc localhost 9000
``` 

#### 6.3. Автоматическое тестирование сервера
```bash
cd build/install/bin/
./check_bulk_server.sh
```
Скрипт автоматически:  
Запускает сервер на порту 10001  
Подключает два клиента с командами 0-9 и 10-19  
Проверяет создание 7 файлов (для bulk_size=3)  
Выводит статистику и содержимое файлов  

#### 6.3. Запуск юнит-тестов
Если вы собирали тесты, вы можете запустить их из каталога сборки:

```bash
cd build/
ctest
```
